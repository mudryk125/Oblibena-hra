# Mindustry - moje oblíbená hra
Mindustry je strategická hra, která kombinuje stavění továren, automatizaci výroby a obranu zakladny. Ve hře získávám suroviny, propojuji budovy dopravníky a bráním se vlnám nepřátel.
## Co mě na Mindustry baví

- Budování továren a výrobních linek.
- Plánování obrany proti nepřátelům.
- Vylepšování základny.
- Hraní s kamarády v multiplayeru.
